# 00-context: source material, read only

Everything Nurix already had when this project started. Seven files: the six-file NuAnchor sales pack
plus one slide about the Unifi aviation hiring project.

**Never edit anything in here, and never put your own analysis here.** The value of this folder is
that it stays exactly as it arrived. When a claim gets challenged in three months, you need the
original, not a version someone tidied up.

Your own notes and analysis go in ../00-context-notes/ instead.

## What's inside

- nuaisle-v0.0/ contains the NuAnchor pack: a release note, an internal deck, a customer deck, a demo
  script, a walkthrough document, and the 3 minute 40 demo recording.
- unifi/ contains one slide. That is the entire Unifi source material that exists.

## The thing to remember

Six of the seven files are about retail buying, which means deciding how much stock to order for next
season and from which factory. That has nothing to do with hiring. The seventh file is about hiring
but for an aviation company, which is structurally different from retail.

So this folder tells you how Nurix builds and sells things, and what the platform can do. It does not
give you evidence about US retail hiring. Read MANIFEST.md before quoting anything from here.
