# Frontline hiring platform

A hiring product for hourly frontline staff at large US retailers, from the moment somebody applies to the
moment they are still on the floor ninety days later.

This repository holds two separate things, and the split is deliberate.

---

## demo/

The working product. From the `demo` folder:

```
node server/index.js
```

Then `http://localhost:4173`. Eleven screens, an overview page, and an assistant you can type at.

**Rebuilt 29 August 2026.** It used to be eleven browser screens over a seed file, opened by double clicking.
It now has a backend: a real domain model, a twenty-six state workflow engine, deterministic eligibility rules,
an event log, an audit trail, and a model boundary. State survives a refresh. It no longer runs from `file://`
and cannot, because the browser holds no data of its own and an API key cannot live in one.

Still no bundler, no framework and no package manager. The server is Node's own `http` module.

Every external system is simulated and says so on screen. Screening evaluations run through a real model when
`LLM_API_KEY` is set in `demo/server/.env`, and print "No model ran" when it is not.

`demo/README.md` explains what is real, what is invented and what is faked. `docs/UPDATE_29_AUG.md` covers what
changed in the rebuild and why. `demo/DEMO-SCRIPT.docx` is the read-aloud script, thirteen scenes, generated by
`demo/make-demo-script.py`.

Run every test with `sh tools/test.sh` from inside `demo/`.

## docs/

Everything written. Start with `docs/CONTEXT.md`, which carries a reading order for the whole set.

The five working records live at the top of that folder:

`CONTEXT.md` for the current state of the project. `DECISIONS.md` for every decision with its reason and the
condition that would reverse it. `OPEN-QUESTIONS.md` for what we do not know, with a name against each one.
`EVIDENCE.md` for every claim with its source and tier, plus the circulating numbers that must not be used.
`TODO.md` for what only Suniras can do. `GAPS.md` summarises what is missing.

Below that, the numbered folders follow the phase model, from `00-context` through `14-operate`. The PRD is in
`07-prd/`.

`docs/shared/` holds documents written for somebody outside this repository. Each one is a dated snapshot and
starts going stale immediately, so check the date before sending anything from there.
