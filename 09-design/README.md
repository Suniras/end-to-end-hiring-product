# 09-design: how it actually feels to use

Phase S2. Two disciplines here, and the second one is easy to skip.

## Interface design

Flows for each type of user. A central recruiter, a store manager, and a candidate want completely
different things from the same underlying system, and a screen built for one is usually wrong for the
others.

## Conversation design, as its own discipline

If there is a voice or chat agent, the conversation is the product, and it needs designing rather than
improvising. That means the actual scripts, how turn-taking works, what happens when someone
interrupts, how the agent confirms it understood correctly, and what tone it takes.

Then the paths people forget: what happens when it goes wrong, and how a human gets involved. Design
escalation deliberately. An agent that cannot hand over cleanly will eventually trap someone.

## Accessibility

There has to be a route through that does not require voice. In US hiring this is an ADA obligation,
not a nice extra. Someone who is deaf, has a speech difference, or simply cannot take a call has to be
able to apply.

Also plan for real conditions: bad phone lines, noise on a shop floor, a range of accents, people
switching between languages mid-sentence, cheap phones, and Spanish-speaking candidates.
