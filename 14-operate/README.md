# 14-operate: running it, and learning from it

Phase S8. The product is live and people depend on it.

## What goes in here

Measurements against the metrics defined in the PRD, using the instrumentation planned back then. If
this folder cannot be filled in, the instrumentation plan failed and you will never know whether the
product worked.

An incident log. What broke, when, what the effect was, and what was done. Written at the time, because
reconstructing it later produces a tidier and less useful account.

An iteration backlog, fed by what actually happens in production rather than what was expected to.

## The loop back

Phase S8 restarts Phase 3. The neat sequence from diagnosis through to launch is scaffolding for
getting a first version out. It is not how product work behaves once something is live. From here,
discovery and delivery run at the same time, continuously.

If launch starts feeling like the finish line, that is the thing to notice.
