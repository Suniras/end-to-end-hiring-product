# synthesis: what the conversations mean

Patterns across the raw notes. This is interpretation, and it is allowed to be wrong, which is exactly
why it is kept away from the raw files.

## Rules

Every claim cites which raw file it came from. If you cannot point at a file, you are remembering
rather than citing, and memory reshapes things.

Count how many people said a thing. One person saying something is an anecdote. Five people
independently saying the same specific thing is a finding. Write which one you have.

Note the contradictions rather than smoothing them over. When a central recruiter and a store manager
describe the same process differently, that gap is usually where the product opportunity sits.
