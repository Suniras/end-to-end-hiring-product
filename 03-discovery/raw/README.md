# raw: never edit these

Verbatim notes and transcripts. One file per conversation. Name files by date and role, for example
2026-09-14-store-manager-midwest-grocery.md.

## Rules

No cleaning up. No summarising. No interpretation. If someone contradicts themselves, leave the
contradiction in, because that is often the most useful thing in the file.

Record what they did, not what they said they would do. Where you paraphrased rather than quoted, mark
it, so later you know which words were actually theirs.

If you want to say what a conversation means, that goes in ../synthesis/.

## Why this matters

In three months a claim in the PRD will get challenged and you will need to show where it came from. A
tidied note cannot do that job. An unedited one can.
