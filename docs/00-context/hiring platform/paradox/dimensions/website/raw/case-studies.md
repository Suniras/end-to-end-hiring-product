## Pattern observed across all 6 fetched case studies

- **No case study on this pass carried a transcribed, attributable text quote from the customer** — every
  named spokesperson is tied to an embedded video/webinar rather than pull-quote text. This is a
  methodological note for anyone trying to cite "customer voice" from the site: the quotes exist as video,
  not as scraped-accessible text.
- Every case study names its product usage precisely (1-4 of the "Conversational X" products), confirming
  customers adopt Paradox modularly rather than as one monolithic suite.
- Stats are uniformly time-to-hire / time-to-schedule / hours-saved / cost-saved / completion-rate — no
  case study cites a quality-of-hire, retention, or diversity-outcome metric.
