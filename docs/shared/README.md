# shared: documents that go to other people

Everything in this folder is written to be read by somebody outside this repo. Moved here on 27 Aug 2026,
because they had accumulated loose at the root alongside the tracking files and the two kinds of document
behave differently.

## The difference that matters

The five files still at the root, CONTEXT.md, DECISIONS.md, EVIDENCE.md, OPEN-QUESTIONS.md and TODO.md, are
**working records**. They are appended to constantly, they contradict earlier versions on purpose, and they
keep withdrawn claims visible so that a reversal can be traced. Nobody outside this project should read them
cold.

Everything in this folder is a **snapshot taken for an audience**. Each one was true on its date and starts
going stale immediately, because the working records keep moving underneath it.

**So the rule for this folder is: check the date at the top before sending anything.** A status document from
three days ago can already contradict a decision, and this project has moved fast enough for that to have
happened more than once.

## Two standing rules for anything sent from here

**Never a number without a source.** Nishant asks where figures come from. EVIDENCE.md carries a list of
circulating numbers that must not be used, and two of them were in a draft that came out of this folder.

**No credentials, ever.** Nothing in this folder, or anywhere in the repo, contains a key, a password or a
workspace credential, and that must stay true. A sandbox API key exists inside 00-context and has never been
opened.
