# 00-context-notes: analysis of the source material

This is where Phase 0 output lives. It is separate from ../00-context/ because that folder holds
untouched source and this folder holds what we made of it.

Every file here starts with an AUTHOR line. That is deliberate. Who wrote something decides what it is
worth, and in a project where the whole point is that Suniras does the thinking, the boundary needs to
be visible in the files themselves rather than remembered.

## What's inside

- capability-inventory.md, written by Claude. Facts only, sorted into proven, claimed, missing, and
  contradictory. It stops short of any opinion about what to reuse.
- nuanchor-one-pager.md, written by Suniras. What NuAnchor does, what it doesn't, and what genuinely
  transfers to hiring.
- unifi-one-pager.md, written by Suniras. What the Unifi work proves about NuPlay, and what doesn't
  carry over to US retail.
- workspace-and-video-notes.md, written by Suniras. The things Claude cannot see, because the demo
  workspace needs a password and the video file cannot be read on this machine.

## Why the split matters

Claude can list what exists. Deciding what any of it means for this product is the actual product
work, and that has to be Suniras's. A great set of documents Claude wrote would mean the project
failed.
