# 11-build: working code

Phase S4. The code lives here.

## The division of labour

Code is Claude's to write. Product decisions are not. Claude does not get to decide scope, drop a
requirement, change acceptance criteria, or declare something finished. Those come back to Suniras.

## Suniras's job during build

Not to disappear. The specific failure mode is going quiet on engineering for a week and then being
surprised, so: available within hours rather than days, protecting the frozen scope, and reviewing
working software every sprint.

Watch for scope changes that happen without anyone consciously deciding them. They arrive as small
reasonable-sounding adjustments and they are how a frozen scope stops being frozen.

## The gate, every sprint

Did you see it working, or did you see a slide about it working?
